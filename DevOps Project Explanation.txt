=====================================================
 DEVOPS PROJECT PRESENTATION (HINGLISH)
 Student Management App
=====================================================


BEFORE PRESENTATION
-------------------
- Docker Desktop on karo (wait: "Engine running").
- Container start karo:   docker start student-app
- GitHub repo ka Actions tab ek tab mein khula rakho.
- Browser mein localhost:3000 check kar lo.


STEP 1: INTRODUCTION
--------------------
- Bolo: "Mera project ek Student Management App hai."
- "Iska goal app banana nahi, DevOps process dikhana hai."
- Flow bolo:
     Code -> GitHub -> Test -> Docker -> CI/CD -> Monitor


STEP 2: GITHUB DIKHAO
---------------------
- Apna repo kholo aur student-devops folder dikhao.
- Bolo: "Mera saara code GitHub par safe store hai."


STEP 3: PIPELINE DIKHAO
-----------------------
- Actions tab kholo aur green tick dikhao.
- Bolo: "Jab bhi main code push karta hoon, GitHub khud tests
  chalata hai aur Docker image banata hai."


STEP 4: DOCKER DIKHAO
---------------------
- Terminal mein chalao:   docker ps
- Bolo: "Mera app Docker container ke andar chal raha hai.
  Isse ye kisi bhi computer par same chalta hai."


STEP 5: APP CHALAKE DIKHAO
--------------------------
- Browser mein kholo:   http://localhost:3000
- Ek student ADD karo aur ek DELETE karo.


STEP 6: MONITORING DIKHAO
-------------------------
- http://localhost:3000/health kholo.
  Bolo: "UP likha hai, matlab app sahi chal raha hai."

- http://localhost:3000/metrics kholo.
  Bolo: "Yahan requests, errors aur memory dikhti hai."


STEP 7: CONCLUSION
------------------
- Bolo: "Is process se manual kaam kam hota hai aur
  deployment tez aur easy ho jata hai."
- Ye bhi bol sakte ho: "Production ke liye main login,
  database aur HTTPS add karunga."


AFTER PRESENTATION
------------------
- App band karne ke liye:   docker stop student-app
